# Stourify 0.5.0

**If you have an older version installed, please replace it with this one — the old build can no
longer reach Stourify at all.**

## You need this update

Stourify's servers moved to a new address. Version 0.4.0 and earlier have the old address built into
them, and the old address no longer answers — so on those versions everything fails: signing in, the
feed, your spots, uploading a photo. It is not a slow connection or a fault on your phone.

The app cannot update itself, which is why you are reading this on the download page rather than
being prompted in the app. Installing this build is the fix.

**Nothing you saved is lost.** Anything you created while offline is still stored on your phone, and
it will send itself once you are signed in again.

## Also in this release
- Settings now scrolls, so **Logout** and **Delete account** can be reached on smaller phones. On a
  short screen they were below the bottom edge with no way to bring them up.
- Opening **Offline & sync** now tries to send whatever is waiting, instead of only reporting it.
- A spot's contributor can hide where it is, and the app no longer shows a position for a spot whose
  owner has hidden it.

## Notes
- The version line at the bottom of the sign-in and Settings screens should read **0.5.0**. If it
  still says 0.4.0, the old app is still installed — remove it and install this one.
